# 执行与检查流程

共同依据为 [角色规范](character-spec.md) 与 [资产索引](../assets/index.md)。不要把参考图上缺失或看不清的部分当成“不需要保留”。尤其单独核对蓝色前胸兜布上的白色工大校标。

## 生成新作品

提取用户要求的比例、姿势、表情、场景、构图，以及明确许可的换装和文字。三头身以已认可的带白色胸标示范作为优先完整参考；六头身以六头身示范结合胸前白色校标局部为主要参考。按需补充目标比例原图、白毛、呆毛、发卡及发羽关系局部。旧三张示范的空白胸兜不作为依据。实际查看并把相应图像交给工具。

提示词先描述本次画面，再突出容易丢失的角色要求：两绺白毛、固定呆毛、对应比例的发羽关系、校徽发卡、白上衣、`#0096C3` 背带短裤及前胸白色校标、眼脸参考、无额外文字。避免把原图版面标题或宣传语复现到新图里。

不因姿势、场景或更换画风擅自删去固定特征；被遮挡的特征无需硬露出。用户明确换装时按本次授权处理，并保持其他身份特征。

## 按用户要求改变画风

用户可以指定水彩、厚涂、像素、三维等画风或提供画风参考。调整媒介、笔触、线条、材质、渲染和光照，同时保留角色规范中的固定要求与本次指定比例。工大蓝是服装基准色，允许受画风、受光与阴影影响表现，不因此替换基准色。

传入图片时明确分工：燕小北参考负责角色身份、结构和标识；画风参考负责视觉技法，不继承其中其他角色的发型、配色、服装或文字。两种用途不能只依赖模型自行猜测。眼脸尽量保持燕小北的识别特征，在目标媒介中合理转译，不强求相同像素。

检查时区分视觉技法差异与角色结构漂移，不能把合理的笔触、材质或明暗变化当成人设错误。大幅风格迁移宜先做一张小样验证识别特征；已经获准的出图范围内可直接执行，无需逐步重复确认。一次成功不代表所有画风都已验证，也不承诺任意画风一次生成完全一致。

## 编辑已有图片

传入编辑目标与必要角色参考，明确用户要改的部位及保持的内容。尽量局部修正，检查修正是否连带改变白毛、呆毛、脸部、发羽关系、发卡和胸前校标。图内已有文字需要按用户本次任务与文字规则处理，不把“改姿势”等请求当作新增文字许可。

## 规范化与补全

1. 查看两张原图和相关示范，列出待处理的具体区域、现有证据与缺口。已有讨论不必重新从零询问。
2. 其他视图能解释的部分，保持设计并恢复清楚表达；已有但模糊的设计，清晰重绘。所有视图都没有依据的结构，需要说明其候选性质，必要时先确认设计方向。
3. 在用户已授权的范围内调用图像工具，不把“检查”“讨论方案”当作生成许可。制作完整人设图时清除非注释性文字，遵守已有注释与新增注释的区别。
4. 可分部位生成候选，或补充确实缺少的视角。不要因为制作规范就强制新增整套三视图、配饰或未确认的身体结构。
5. 对照检查，交给作者确认。作者认可某个局部不等于认可图中所有新增结构；未确认补全不能纳入正式参考。

原始图片保留不覆盖。后续若作者确认新的正式规范图，将其与来源、认可范围一起记录并更新资产索引；不能静默把一次日常作品设为新标准。

## 检查一致性

仅检查时实际看图并报告，默认不调用生成。按“符合／需修正／因遮挡或清晰度无法核实”判断，不把看不清当通过，也不把合理遮挡当缺陷。

| 检查项 | 重点 |
| --- | --- |
| 白毛 | 左右各一绺，形状依据三头身原图左侧大立绘；不是额外挑染或高光。 |
| 呆毛与脸部 | 固定呆毛、参考发色、眼睛与脸部。 |
| 比例与发羽 | 正常三／六头身；六头身连续渐变，三头身分开。 |
| 发卡 | 北京工业大学校徽样，无附加装饰，没有简化为任意 B 字。 |
| 默认服装 | 白上衣和工大蓝背带短裤；以本次授权的换装例外为准。 |
| 胸前校标 | 蓝色前胸兜布上的**白色北京工业大学校标**存在且符合参考，未被替换成普通图案。 |
| 雨燕伙伴 | 出现时造型参考正确，作为独立伙伴。 |
| 文字 | 无未经允许的文字、字母装饰、伪文字、水印或背景字样；不误删指定校徽与胸前校标。 |
| 补全与漂移 | 没有把未确认的新结构升级为固定人设；修正未引起其他关键部位漂移。 |

需要修正时指出位置、违反的已确认要求和建议修改范围。不要用审美偏好否定作者已认可的造型。可在授权范围内针对局部迭代；若反复失败，说明尚存问题，不假称完全一致。
